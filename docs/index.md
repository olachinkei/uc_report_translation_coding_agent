# Repository Knowledge Index

This directory is the repository-local system of record for agents and humans.

Start here:

- `ARCHITECTURE.md`: repository layout, ownership boundaries, and data flow
- `OPERATIONS.md`: translation, corpus maintenance, and output handling workflows
- `QUALITY.md`: validation gates, lint rules, and quality expectations
- `adr/`: durable decisions; add new ADRs instead of rewriting history
- `generated/`: script-generated indexes; do not edit by hand

Agent entry points such as `AGENTS.md` and `CLAUDE.md` should point here instead of duplicating these details.
